# 🏋️ FitTrack — Daily Fitness & Health Tracker

This is a Java desktop application that cross-references your sleep, nutrition, and workout data to generate personalized daily coaching messages.

## Features
- 🍗 Log daily meals with protein, carbs, and fat tracking
- 💪 Log workouts with duration and calorie burn estimates
- 😴 Sleep tracking with personalized recovery feedback
- 📊 Smart daily coaching that combines ALL three data points
- ⚠️ Recovery alert system when sleep and training are misaligned
- 📅 Persistent report history — save, view, and delete past reports
- 🎯 Goal-based nutrition targets (Bulk / Cut / Maintain)

## How to Run
1. Make sure Java is installed on your computer
2. Download `FitTrack.jar` from the `target` folder
3. Open PowerShell or Terminal and run:
java -jar FitTrack.jar


## Tech Stack
- Java 21
- Java Swing (GUI)
- Maven (build tool)
- JUnit 5 (testing)
